# Parameter definitions for tools/gen-params/gen_params.py.
# Columns separated by |:  Lookup | Path (after VRCOSC/Hardware/) | Type | Parity | Display name | Description
# Type: bool, int, float. Parity: yes for the 14 official parameters, else no.
# A line starting with "@slots N" repeats the following block (until "@end") for slot 0..N-1; {N} is the slot number.
# Enum member names and ordering identify saved VRCOSC parameter lookups.

# GPU, selected group
GpuUsage | GPU/Usage | float | yes | GPU Usage | Selected GPU utilization 0..1 (Task Manager definition by default)
GpuPower | GPU/Power | int | yes | GPU Power | Selected GPU power in watts, clamped 0..255
GpuTemp | GPU/Temp | int | yes | GPU Temp | Selected GPU temperature in degrees C, clamped 0..255
GpuUsagePercent | GPU/UsagePercent | int | no | GPU Usage Percent | Selected GPU utilization 0..100
GpuTempNormalized | GPU/TempNormalized | float | no | GPU Temp Normalized | Selected GPU temperature divided by MaxGpuTempC, 0..1
GpuPowerNormalized | GPU/PowerNormalized | float | no | GPU Power Normalized | Selected GPU power divided by MaxGpuPowerW, 0..1
GpuCoreClock | GPU/CoreClock | float | no | GPU Core Clock | Selected GPU core clock divided by MaxGpuClockMhz, 0..1
GpuMemoryClock | GPU/MemoryClock | float | no | GPU Memory Clock | Selected GPU memory clock divided by MaxGpuClockMhz, 0..1
GpuFan | GPU/Fan | float | no | GPU Fan | Selected GPU fan speed 0..1
GpuPresent | GPU/Present | bool | no | GPU Present | True while the selected GPU exists and has fresh data
GpuIsIntegrated | GPU/IsIntegrated | bool | no | GPU Is Integrated | True if the selected GPU is integrated
GpuIsDiscrete | GPU/IsDiscrete | bool | no | GPU Is Discrete | True if the selected GPU is discrete
GpuIndex | GPU/Index | int | no | GPU Index | Slot index (0..3) of the selected GPU, 255 if it has no slot

# VRAM of the selected GPU (5)
VramUsage | VRAM/Usage | float | yes | VRAM Usage | Selected GPU memory used / total, 0..1 (shared system memory on integrated GPUs)
VramTotal | VRAM/Total | int | yes | VRAM Total | Selected GPU memory total in GiB, clamped 0..255
VramUsed | VRAM/Used | int | yes | VRAM Used | Selected GPU memory used in GiB, clamped 0..255
VramFree | VRAM/Free | int | yes | VRAM Free | Selected GPU memory free in GiB, clamped 0..255
VramUsagePercent | VRAM/UsagePercent | int | no | VRAM Usage Percent | Selected GPU memory used 0..100

@slots 4

Gpu{N}UsagePercent | GPU/{N}/UsagePercent | int | no | GPU {N} Usage Percent | Slot {N} GPU utilization 0..100
Gpu{N}Temp | GPU/{N}/Temp | int | no | GPU {N} Temp | Slot {N} GPU temperature in degrees C, clamped 0..255
Gpu{N}Power | GPU/{N}/Power | int | no | GPU {N} Power | Slot {N} GPU power in watts, clamped 0..255
Gpu{N}IsIntegrated | GPU/{N}/IsIntegrated | bool | no | GPU {N} Is Integrated | True if the slot {N} GPU is integrated
Gpu{N}VramUsage | GPU/{N}/VRAMUsage | float | no | GPU {N} VRAM Usage | Slot {N} GPU memory used / total, 0..1
Gpu{N}VramPercent | GPU/{N}/VRAMPercent | int | no | GPU {N} VRAM Percent | Slot {N} GPU memory used 0..100
@end

# CPU (9)

CpuFrequency | CPU/Frequency | float | no | CPU Frequency | CPU frequency divided by MaxCpuClockMhz, 0..1
CpuPresent | CPU/Present | bool | no | CPU Present | True while CPU usage data is fresh
CpuSensorsPresent | CPU/SensorsPresent | bool | no | CPU Sensors Present | True while CPU power and temperature are valid
